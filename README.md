# 拾光手机工坊

在浏览器制作一部可以探索的虚构手机，包含微信、相册、短信、电话、音乐、淘宝和支付宝故事界面。

在线使用：<https://1842a-droid.github.io/shiguang-phone-studio/>

下载 `index.html` 后也能双击打开。编辑内容保存在浏览器里，请用“备份项目 JSON”保存进度。

## 分享与迁移

- “生成并复制分享链接”使用本站 GitHub Pages 地址，作品数据保留在 `#p=` 片段中。
- 图片或音频很多时，导出单个作品 HTML 分享。
- 旧 `chatgpt.site` 作品链接可在“转换旧作品链接”中转换，不改变原作品数据。
- 旧站编辑进度需先导出项目 JSON，再在新站导入。各域名的浏览器存档相互独立。

## 音乐

编辑时填写歌名和歌手，在作品里点击歌曲即可自动匹配，尝试播放网易云官方可公开播放的版本。会员、下架和受平台限制的歌曲可能无法播放，可使用备用音源中的本地文件。不会自动用其他歌手或其他版本替代所填歌曲。

搜歌元数据由 [GD音乐台](https://music.gdstudio.xyz/) 提供，仅用于非商业学习用途，请遵守其[使用说明](https://music-api.gdstudio.xyz/api.php)。播放使用网易云官方外链，不使用付费解锁功能。搜索服务有缓存及限流，不需要配置密钥。

所有聊天、账单、红包和转账均为虚构故事互动，不连接真实账号或支付。

## 发布

GitHub Pages 发布来源：`main` 分支的根目录，使用 `.nojekyll`。网站为纯静态 HTML，不需要构建或服务器，也不依赖 GPT 域名。实际网络可达性仍取决于访问者所在地网络。
